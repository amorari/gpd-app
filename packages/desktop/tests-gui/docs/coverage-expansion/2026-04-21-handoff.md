## How to pick up in the VM

```bash
git clone https://github.com/amorari/gpd-app.git
cd gpd-app
git checkout feature/gui-test-suite
cd packages/desktop
bun install --frozen-lockfile
bun run predev                                   # build opencode-cli sidecar
bun run tauri build --debug                      # build GPD Dev.app
cd tests-gui
uv sync
```

Then launch GPD Dev and run:

```bash
bash scripts/run_full_sweep.sh
```

Grant **Accessibility** to `GPD Dev` in System Settings → Privacy → Accessibility (prompted on first AX query).
