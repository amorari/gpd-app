# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

Be respectful. Assume good faith. Focus on what's best for the project
and community. Harassment, personal attacks, and discriminatory language
are not tolerated.

## Reporting

Report conduct concerns to `gpd@psi.inc`. Reports are confidential. The
maintainers will investigate and respond.

For security vulnerabilities, use `SECURITY.md` instead.

## Scope

Applies to project spaces (repo, issues, PRs, discussions) and public
representation of the project (conference talks, social posts tagging
the project, etc.).

## Enforcement

The maintainers may warn, temporarily ban, or permanently ban
contributors who violate this code. Appeals go to the same address.
